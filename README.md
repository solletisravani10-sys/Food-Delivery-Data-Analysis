# Food Delivery Data Analysis using Power BI

## Project Overview
This project focuses on analyzing food delivery data using Microsoft Power BI. The dashboard provides insights into sales performance, customer behavior, order status, food categories, and delivery performance.

## Project Objectives
- Analyze total sales and orders.
- Identify top-performing cities.
- Understand customer purchasing behavior.
- Analyze food category performance.
- Track delivered, cancelled, and pending orders.
- Evaluate delivery time and customer ratings.

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV

## Dataset Information
The dataset contains 1,200 records and 18 columns.

Important columns include:
- Order ID
- Order Date
- Customer ID
- Restaurant Name
- City
- Food Category
- Quantity
- Unit Price
- Discount
- Amount
- Order Status
- Payment Mode
- Delivery Time
- Customer Rating

*Note: This is a synthetic dataset created for learning and analysis purposes.*

## Key Performance Indicators (KPIs)
- Total Orders
- Total Sales
- Total Customers
- Total Quantity
- Average Order Amount
- Average Customer Rating
- Average Delivery Time
- Delivery Success Percentage

## Dashboard Analysis
1. Sales Analysis
2. City-wise Sales Analysis
3. Food Category Analysis
4. Order Status Analysis
5. Payment Mode Analysis
6. Monthly Sales Trend
7. Delivery Performance Analysis

## Conclusion
This project helps understand food delivery business performance through interactive visualizations and data analysis. It provides insights into sales trends, customer preferences, and delivery operations.
